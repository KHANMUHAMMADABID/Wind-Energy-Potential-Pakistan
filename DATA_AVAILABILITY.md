# Data availability and access conditions

## Publicly available materials in this repository

This repository contains author-generated materials supporting the study:

- analysis scripts;
- station metadata;
- data-availability summaries;
- derived wind-speed products;
- multi-height WPD and WED datasets;
- reanalysis-validation metrics;
- composite-ranking results;
- HAC-robust trend-analysis outputs;
- Ordinary Kriging variogram and cross-validation diagnostics;
- turbine-performance results;
- province-level techno-economic results;
- selected final figures and figure source data.

## Data not redistributed

Raw meteorological observations obtained from the Pakistan Meteorological
Department are not redistributed unless explicit permission has been obtained
from PMD.

Raw downloaded ERA5, JRA-55, and NCEP/NCAR files are also not redistributed
unless their respective provider terms permit redistribution.

## Official data sources

- Pakistan Meteorological Department: https://weather.gov.pk/
- ERA5 / Copernicus Climate Change Service:
  https://climate.copernicus.eu/
- JRA-55 / Japan Meteorological Agency:
  https://jra.kishou.go.jp/JRA-55/index_en.html
- NCEP/NCAR Reanalysis / NOAA NCEI:
  https://www.ncei.noaa.gov/

## Reproducibility

The scripts and derived outputs are organized by analysis component. Consult
the README file in each folder before executing the workflow.
